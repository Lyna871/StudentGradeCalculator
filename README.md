# Student Grade Calculator ☕

A simple Java console application that calculates a student's total grades, average grade, and pass/fail status based on three subject grades.

## Features
- Accepts grades for three subjects using Java Scanner.
- Calculates the total and average grades.
- Determines whether the student passes or fails.
- Uses conditional statements (`if-else`) for decision-making.

## Technologies Used
- Java
- IntelliJ IDEA
- Git & GitHub

## Example Output

```text
Enter grades for subject 1
75
Enter grades for subject 2
79
Enter grades for subject 3
78

Total grades: 232
Total Average: 77.0
pass
```
